Crypto Agent · Python-only core

一个由 Python LangGraph 编排的研究与交易系统

当前主线已经移除旧 TypeScript agent、Ink UI、npm 包、Vitest 测试和 Node systemd。 生产入口只剩 Python daemon、Python 工具层、Python 交易层、SQLite 和 Docker。

Python 3.12 LangGraph SQLite PaperBroker RiskGate Docker

系统边界

Agent 层

crypto_agent/agents/ 负责图编排、resident run 审计和工具调用。它决定流程，不直接拥有账户账本。

工具层

crypto_agent/tools/ 暴露受控原语，例如创建策略包、验证策略、部署策略、查询组合和开仓。

交易层

crypto_agent/trading/ 负责 paper 账本、风险门禁、订单执行和 OKX live adapter contract。

运行图

闭环链路

核心不变量是所有研究、策略、下单和风控拒绝都能回溯到同一条身份链： funding_account -> trading_account -> trading_bot -> bot_allocation -> resident_agent -> agent_run。

阶段模块产物
建库crypto_agent/db/schema.py默认 funding、trading account、bot、allocation。
研究researcher_graph.py策略包、验证报告、KB 记录。
验证backtest/validators.py通过或失败的 validation report。
交易trader_graph.py策略部署、paper order、fill、position、trade。
风控trading/risk_gate.py允许订单或持久化 risk denial。

命令入口

本地验证

python3 -m venv .venv
. .venv/bin/activate
pip install -e ".[dev,agent]"
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest tests_py -q

闭环烟测

crypto-agent-py smoke \
  --database-path data/smoke.db \
  --profile-path agents/residents/btc-eth-researcher/AGENT.md \
  --destructive

Daemon

crypto-agent-py daemon \
  --database-path data/crypto_agent.db \
  --socket-path /tmp/crypto-agent-py.sock \
  --environment development \
  --init-db

Docker

mkdir -p data runtime
docker compose up -d --build
docker compose exec crypto-agent \
  crypto-agent-py-client \
  --socket-path /run/crypto-agent/crypto-agent.sock \
  health

当前限制

Live 交易

OKX adapter 已有参数级实现和测试，但真实私有账户预检和真实下单仍需要单独 readiness pass。

UI
